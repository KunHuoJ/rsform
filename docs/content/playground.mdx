## Playground 样板间

一个「采购订单创建」表单，把 rsform 全部能力揉进一个真实业务场景，提交拿到完整数据。

### 覆盖的能力

- **基础控件**：Input / TextArea / InputNumber / Select / RadioGroup / Switch / DatePicker（含 string↔Dayjs 边界转换）
- **级联 Select**：`$.linkedFieldProps` 异步派生子分类 options
- **跨字段校验**：`$.validateField` 交付日期必须晚于下单日期
- **ArrayItems**：联系人列表，`min`/`max`/`validateBeforeAdd` + 跨行唯一手机号 + 正则格式校验
- **Table**：物料明细，列级 `required` + `validator` + 按行派生 `total` + `date` + `switch` + 操作列（上移/插入/删除）
- **按行联动**：`$.onEachRowMultiChange` 监听 qty/price，任一变化重算 total 写入 `form.values`
- **Form.Consumer**：实时汇总（联系人数、物料数、合计金额）
- **validateFailed="scroll"**：校验失败滚到首个错误
- **编程式重置**：`formRef.current.reset()`
- **Submit**：校验通过后拿到 `toJS` 后的普通对象

### 试这些交互

1. 清空「订单名称」再提交 → 校验拦截、滚到错误格、`onSubmit` 不触发。
2. 选「下单日期」晚于「交付日期」→ 交付日期下方报"必须晚于下单日期"。
3. 切换「物料分类」→ 「子分类」options 异步重新加载。
4. 在物料表里改任一行的「数量」或「单价」→ 该行「小计」实时更新，底部合计同步变化，**其余格不重渲染**。
5. 联系人里填两个相同手机号 → 报"手机号重复"；填非 11 位 → 报"请输入有效手机号"。
6. 点「重置」→ 表单回到初始值。
7. 全部填合法 → 点「提交订单」→ 底部输出完整 JSON（普通对象，可直接 `JSON.stringify`/送接口）。
