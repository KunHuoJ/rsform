## API 参考

### Form

表单容器。底层 `createForm` + `FormProvider`，children 外包一层空 `preName` 的
`FieldContext.Provider`，让相对路径 Field 能解析。

```jsx
import {Form} from 'rsform';
```

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `form` | `FormilyForm` | 内部创建 | 外部表单实例；省略则 rsform 创建 |
| `initialValues` | `Record<string, any>` | — | 初始值 |
| `asyncInitialValues` | `() => Promise<Record>` | — | 异步初始值；表单等其 resolve 后挂载。loading 期间渲染 `<div className="rsf-form-loading">loading…</div>`，不可定制 |
| `effects` | `EffectFn \| EffectFn[]` | — | effect 回调，注入 `$` helper 包；数组按序扇出 |
| `onSubmit` | `(values) => void \| Promise` | — | 提交回调。**校验通过后才执行**——校验失败时 onSubmit 不跑，表单不会提交脏数据 |
| `onReset` | `() => void` | — | ⚠️ **暂未生效**（占位 API，保留以稳定签名）。重置走 `formRef.current.reset()` |
| `validateFirst` | `boolean` | — | 遇到第一个校验错误即停止 |
| `validateFailed` | `'scroll' \| (field) => void` | — | 校验失败处理：`'scroll'` 滚到首个错误，或传自定义回调。**不传则不处理** |
| `formRef` | `MutableRefObject` | — | 拿到 form 实例的 ref |
| `children` | `ReactNode` | — | 表单内容 |

`Form` 命名空间挂载：`Form.Field` / `Form.Consumer` / `Form.Formily`（核心）+
`Form.Input` / `Form.TextArea` / `Form.InputNumber` / `Form.Select` / `Form.RadioGroup` /
`Form.Switch` / `Form.DatePicker` / `Form.Submit` / `Form.Button`（antd 控件）+ `Form.Table` / `Form.ArrayItems`。
全部从单入口 `import { Form } from 'rsform'` 拿到，无需多 import + 起别名。

### Form.Field

字段单元。包 Formily `<Field>`，用 `commonMap` 自动把 `field.value` / `field.onInput`
桥接成 antd 控件的 `value` / `onChange`，无需手写受控样板。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | `string` | — | 字段路径；支持相对路径 `.foo` / `..foo`（在 ArrayItems 行内） |
| `title` | `ReactNode` | — | label 文本 |
| `required` | `boolean` | — | 显示红星 **且** 触发 Formily 内置非空校验（submit 空值被拦截）。自定义规则另配 `validator`，两者叠加 |
| `editable` | `boolean` | `true` | `false` 渲染为 `NonEditable` 文本态 |
| `format` | `(value) => any` | — | 写入控件前变换值 |
| `parse` | `(value) => any` | — | 控件 onChange 后写入表单前变换值 |
| `selectFirst` | `boolean` | — | 挂载时自动选首项（单选 option 控件） |
| `hideUi` | `boolean` | — | 只渲染控件，无 label/error 外壳 |
| `requiredOnlyUi` | `boolean` | — | 只渲染红星 + 控件，隐藏 title |
| `validator` | `FormilyValidator` | — | Formily 校验器 |
| `reactions` | `FormilyReactions` | — | Formily 字段 reactions |
| `basePath` | `string` | — | Formily basePath 覆盖 |
| `children` | `ReactElement \| (api) => Node` | — | 控件元素，或 render-prop |

`children` 为 render-prop 时收到 `{value, onChange, state}`，用于自定义控件。

### Form.Submit

提交按钮。包 antd `Button`，点击调 `form.submit()`，提交/校验期间显示 loading。提交先跑整表校验；**校验失败则拦截 onSubmit**（onSubmit 挂在 `onFormSubmitSuccess`，只在通过后执行）。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `onSubmit` | `(values) => void \| Promise` | Form 的 onSubmit | **覆盖** Form 的 onSubmit（仅本次点击）：传了它，`<Form onSubmit>` 就**不会**触发；不传则走 Form 的。校验失败时两者都不跑 |
| `preventDuplicate` | `boolean` | `false` | 防重复提交。① 同步重入锁——同一 tick 内连点只跑一次 `form.submit()`；② 成功提交后按钮锁定（一次性），直到 `form.reset()` 才解锁，避免同一表单提交两次 |
| `children` | `ReactNode` | — | 按钮文字 |
| 其余 | — | — | 透传 antd `Button` 的所有 props（除 `onClick`/`htmlType`/`loading`） |

### Form.Consumer

render-prop 订阅表单值。底层 `observer` + `form.values`/`form.getValuesIn`，只追踪读到的叶子，所以只有那片数据变化才重渲染。

```jsx
// 订阅整个表单值
<Form.Consumer>{values => <span>{values.name}</span>}</Form.Consumer>

// 只订阅单个字段——只有该叶子变化才重渲染
<Form.Consumer name="name">{name => <span>{name}</span>}</Form.Consumer>
```

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | `string` | — | 字段路径；省略则订阅整个 `form.values`。支持相对路径（`.foo` 在 `Form.Field` 内解析到当前行） |
| `children` | `(data) => ReactNode` | — | render-prop：接收订阅到的数据并返回节点。`name` 省略时 `data` 是整个 `form.values`；有 `name` 时 `data` 是该字段值 |

> `children` 是纯渲染函数，不要在里面写副作用（写状态/发请求）；需要副作用用 `effects` 里的 `$.onFieldValueChange`。

### useFormDraft

草稿自动保存 / 恢复 hook。在 `<Form>` 内部调用，给定业务语义稳定的 key，表单每次值变化防抖写进 `localStorage`，提交成功后草稿自动清除，重新进入发现历史草稿时 `hasDraft` 为 `true` 供渲染恢复横条。

```tsx
import {useFormDraft} from 'rsform';

const draft = useFormDraft('order-edit', {debounceMs: 400});
// draft.hasDraft / draft.restore() / draft.dismiss() / draft.clear()
```

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `key` | `string` | — | 草稿存储 key（业务语义命名，同一种表单复用同一 key） |
| `options.debounceMs` | `number` | `500` | 防抖保存间隔 |
| `options.storage` | `Storage` | `window.localStorage` | 存储后端；SSR/测试可传 mock。`window` 不存在时 hook 降级为 no-op |
| `options.clearOnSubmit` | `boolean` | `true` | 提交成功（`ON_FORM_SUBMIT_SUCCESS`）后自动清草稿 |
| `options.maxAge` | `number` | — | 草稿有效期（ms）；过期草稿读取时即被清除 |

返回 `{ hasDraft, draft, restore(), dismiss(), clear() }`。详见「草稿恢复」页。

### 控件

薄 antd 5 控件 re-export，加静态 `__rsfOptionControl` 标记供 Table 控件注册识别。

| 控件 | 等价 antd | 说明 |
|---|---|---|
| `Form.Input` | `Input` | 输入框 |
| `Form.TextArea` | `Input.TextArea` | 多行输入 |
| `Form.InputNumber` | `InputNumber` | 数字输入 |
| `Form.Select` | `Select` | 下拉选择；支持 `options`/`mode` 等 antd props |
| `Form.RadioGroup` | `Radio.Group` | 单选组；默认 `optionType='button'` |
| `Form.Switch` | `Switch` | 开关；自动把 `value` 互换成 `checked` |
| `Form.DatePicker` | `DatePicker` | 日期选择；传给 `Form.Field` 时需用 `format`/`parse` 做 string↔Dayjs 转换（表格列用 `'date'` 已内置 `DateCell`） |
| `Form.Button` | `Button` | antd Button re-export，方便自定义操作按钮 |

控件可直接 import：`import {Select} from 'rsform'`，或走 `Form.Select` 命名空间。

#### 自定义控件注册（Table）

Table 的 `control` 列属性有三种写法，**都共享同一份性能契约**（CellBridge 注入 value/onChange、只订阅叶子、支持 validator/effects）：

1. **字符串 key**（`'input'`/`'inputNumber'`/`'select'`/`'radioGroup'`/`'switch'`/`'date'`）：从 `FormComMap` 注册表查。自定义控件用 `registerControl` 注册后即可复用：

```tsx
import {registerControl} from 'rsform';

registerControl('companyPicker', CompanyPicker);
// 之后列里可用 control: 'companyPicker'
```

`getControl(key)` 查单个、`getControls()` 查全部（返回防御性拷贝）。

2. **组件类型**（`control: CompanyPicker`）：直接传组件类型，配合 `controlProps` 最自然，无需注册。

3. **元素**（`control: <CompanyPicker companies={...} />`）：一次性，CellBridge 用 `cloneElement` 注入 value/onChange。

自定义控件只需接收 `value` / `onChange`（传裸值或 event 均可），无需感知 Formily/rsform。详见「可编辑表格」页的[自定义控件](#自定义控件)小节与完整示例。

> ⚠️ 类实例（dayjs/moment 等）不要直接进 `form.values`——Formily 响应式 Proxy 会序列化它。仿照内置 `'date'`（`DateCell`，存 ISO 字符串、边界转 Dayjs），在控件边界做值类型转换。

### Form.Table

高性能可编辑表格。单元格**不是** Formily Field——只订阅 `form.values` 的叶子节点，
编辑一格只重渲染该格。

```tsx
import {Form} from 'rsform';

<Form.Table<Row> name="rows" columns={[...]} />
```

#### Form.Table props

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | `string` | — | 数组字段名 |
| `columns` | `RsfTableColumn[]` | — | 列定义（见下） |
| `rowKey` | `string \| (record, index) => Key` | 绝对行号 | 行 key |
| `pagination` | `false \| object` | `false` | antd 分页；默认不分页。⚠️ 用分页时必须**受控**传 `current`/`pageSize`——非受控分页下 `useTable` 拿不到当前页，跨页单元格路径会错位 |
| `scroll` | `object` | 见说明 | antd `scroll`。省略时 rsform 按列 `width` 求和算 `scroll.x`（让每列 `width` 严格生效，固定布局）；无列声明 width 时回退 `'max-content'`。传自定义则覆盖 |
| `itemDefaultValue` | `any` | `{}` | `actions.add`/`actions.insert` 不传 value 时的默认行值 |
| `max` | `number` | — | 行数上限；到上限后 `actions.add`/`actions.insert` 静默拒绝 |
| `min` | `number` | `0` | 行数下限；到下限后 `actions.remove` 静默拒绝 |
| `validateBeforeAdd` | `boolean \| (values, itemDefault) => boolean \| string \| void` | `false` | `add`/`insert` 前门禁。`true`：先 `form.validate(\`${name}.*\`)` 校验已有行，有错拒绝。传函数同 `ArrayItems` 签名自定义门禁 |
| `tableProps` | `object` | — | antd `Table` props 透传（`virtual`/`bordered`/`size`/`rowSelection`/`onChange`/`onRow`/`sticky`…）。rsform 接管的 `columns`/`dataSource`/`pagination`/`rowKey`/`scroll` 优先 |
| `className` | `string` | — | 表格包装类名 |

#### RsfTableColumn

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `title` | `ReactNode` | — | 列标题 |
| `dataIndex` | `string` | — | 行对象里对应此列的 key |
| `width` | `number \| string` | — | 列宽 |
| `control` | `ControlKey \| ComponentType \| ReactElement` | — | 控件：字符串 key（`'input'`/`'inputNumber'`/`'select'`/`'radioGroup'`/`'switch'`/`'date'`，IDE 自动补全）、组件类型（`control: MyInput`）、或 React 元素；省略=只读文本。三种写法见上方[自定义控件注册](#自定义控件注册table) |
| `editable` | `boolean` | `true`（有 control 时） | 单元格是否可编辑 |
| `required` | `boolean` | `false` | 是否必填（列级）。`true` 时空值校验失败，提交被拦截、错误显示在单元格下方。**不是 `controlProps.required`**（那只设 HTML 属性） |
| `requiredMessage` | `string` | `'必填'` | `required` 校验失败时的错误信息 |
| `validator` | `FormilyValidator` | — | 单元格校验器。`required` 规则组合在 `validator` 前：空值先报必填、非空才跑 validator |
| `controlProps` | `object` | — | 控件额外 props（options/placeholder 等）。`controlProps.required` 只设 antd 控件 HTML 属性，不进 Formily 校验 |
| `align` | `'left' \| 'center' \| 'right'` | — | 对齐 |
| `fixed` | `'left' \| 'right' \| boolean` | — | 固定列 |
| `render` | `(value, record, index, actions) => Node` | — | 完全自定义渲染（覆盖 CellBridge）。`actions` 提供 `add`/`insert`/`remove`/`move`/`moveUp`/`moveDown`/`form`/`field`，可在任意列放操作按钮 |

> `render` 的 `actions`（`RsfTableColumnActions`）：`add(value?)`、`insert(index, value?)`、`remove(index)`、`move(from, to)`、`moveUp(index)`、`moveDown(index)`、`form`、`field`。`add`/`insert` 默认用 `itemDefaultValue`。

### Form.ArrayItems

轻量增删列表，类似 antd `Form.List`。基于 Formily `ArrayField` mutators。默认只给
删除按钮；上下移动按需开启（`sortable`）。添加/删除均可自定义按钮或拦截。

```jsx
import {Form} from 'rsform';

<Form.ArrayItems name="tags" itemDefaultValue={{label: ''}}>
  {() => <Form.Field name="label"><Form.Input /></Form.Field>}
</Form.ArrayItems>
```

#### props

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | `string` | — | 数组字段名；支持相对路径 |
| `itemDefaultValue` | `any` | `{}` | 新增行默认值 |
| `min` | `number` | — | 最小行数，到限禁用删除 |
| `max` | `number` | — | 最大行数，到限禁用新增 |
| `validateBeforeAdd` | `(values, itemDefault) => boolean \| string \| void` | — | 新增前门禁；`false` 静默阻止，`string` 报错 |
| `addDisabled` | `boolean` | `false` | 隐藏内置新增按钮（配合 `renderAdd`） |
| `addText` | `ReactNode` | `'添加'` | 内置新增按钮文字 |
| `renderAdd` | `(add: () => void) => ReactNode` | — | 完全自定义新增按钮；提供后内置按钮不渲染 |
| `removeText` | `ReactNode` | `'×'` | 内置删除按钮文字 |
| `onRemove` | `(index, values) => boolean \| Promise<boolean>` | — | 删除前拦截；返回 `false` 取消（用于二次确认） |
| `renderRemove` | `(index, remove: () => void) => ReactNode` | — | 完全自定义删除按钮；提供后内置按钮不渲染 |
| `sortable` | `boolean` | `false` | 是否显示上移/下移按钮；多数表单不需要排序 |
| `children` | `(value, index) => ReactNode \| ReactNode` | — | 行内容；render-prop 内用相对路径 Field |

#### 相对路径

`children` 是 render-prop 时，内部 `Field name="label"` 会解析到当前行
（`name.0.label`、`name.1.label`...），无需手拼路径。

#### 行操作

默认每行行末一个删除按钮。`sortable` 开启后额外显示上移/下移（走 Formily
`moveUp`/`moveDown`）。`renderRemove` 可整行替换删除按钮；`onRemove` 可在删除前
拦截（如弹确认框，返回 `false` 取消）。`renderAdd` 同理替换底部新增按钮。

#### 跨行唯一校验 `arrayUnion`

`arrayUnion(key, message?)` 返回一个 validator，挂在行内 `<Field validator={arrayUnion('email')}>` 上，自动读取最近数组祖先，若该 `key` 在其他行已出现则报错。

```tsx
import { arrayUnion, Form } from 'rsform';

<Form.Field name="email" validator={arrayUnion('email', '该邮箱已存在')}>
  <Form.Input />
</Form.Field>
```
