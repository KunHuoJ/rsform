## 介绍

**rsform** 是基于 Formily v2 + antd 5 的高性能 React 表单库。

- **Effect 驱动**：在 `effects` 回调里用 `$` helper 声明字段联动，跨字段校验、级联派生一键搞定。
- **自动注入 Field**：把控件丢进 `Form.Field`，value/onChange 自动流转，无需手写受控样板。
- **高性能表格**：单元格非 Formily Field，编辑一格只重渲染该格，N×M 表格不卡。
- **ArrayItems 可增删列表**：Formily ArrayField mutators，增删/上下移开箱即用，类似 antd Form.List，零拖拽依赖。
- **统一入口**：混用控件 + Table/ArrayItems 时 `import { Form } from 'rsform'` 一个 `Form` 拿到全部语法糖，无需多入口 + 起别名。

### 技术栈

- 引擎：`@formily/core` + `@formily/react` v2（开源 MIT）
- UI：antd 5 + React 19
- 打包：`@rslib/core`（bundleless）；文档：Vite + MDX；测试：Vitest

### 为什么有 rsform

Formily 的响应式引擎很强，但直接用 `@formily/react` 样板太多——每个字段要手写
`value/onChange`、联动要手动订阅、可编辑表格每个格子做成完整 Field 导致 N×M 订阅卡顿。
rsform 薄壳封装：

1. **自动注入**：`Form.Field` 自动用 `commonMap` 把 Formily 的 `field.value`/`field.onInput`
   桥接成 antd 控件的 `value`/`onChange`。
2. **effect 糖**：`effects={$ => ...}` 注入常用 helper 集，声明式联动。
3. **高性能表格**：单元格只订阅叶子值，写入走 `onInput`，编辑一格只重渲染一格。
