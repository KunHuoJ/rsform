## 快速上手

### 安装

rsform 是单包多入口，按需从子路径导入：

```sh
pnpm add rsform @formily/core @formily/react antd react react-dom
```

### 子路径导出

| 子路径 | 内容 |
|---|---|
| `rsform` | 核心：Form / Field / FormError / Formily（无 antd 依赖） |
| `rsform/antd` | antd 控件 + Submit（挂在 `Form.Input` 等命名空间） |
| `rsform/table` | 高性能可编辑表格 Form.Table |
| `rsform/array-items` | 可增删/拖拽列表 Form.ArrayItems |
| `rsform/effects` | effects `$` helper 集合 |
| `rsform/styles` | base 样式表（CSS 变量主题） |

### 最小示例

```jsx
import 'rsform/styles';                 // 引入默认 antd 风格主题（可选）
import { Form } from 'rsform/antd';

<Form initialValues={{ name: '' }} onSubmit={async v => console.log(v)}>
  <Form.Field name="name" title="姓名" required>
    <Form.Input />
  </Form.Field>
  <Form.Submit>提交</Form.Submit>
</Form>
```

> rsform 薄壳包裹 antd 5 控件与 Formily v2 引擎。`@formily/*`、antd、react 均为
> peer 依赖——消费者复用同一份 formily 实例，避免响应式失效。

### 主题定制

所有视觉 token 是 `--rsf-*` CSS 变量，覆盖即可定制：

```css
:root {
  --rsf-color-primary: #722ed1;   /* 主色 */
  --rsf-color-error: #f5222d;     /* 错误色 */
  --rsf-label-color: #262626;     /* label 色 */
}
```

完整变量清单见 [主题变量](#tokens)。
