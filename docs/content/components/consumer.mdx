# 订阅表单值

> `Form.Consumer` 是 render-prop 订阅组件：`children` 写成函数，接收订阅到的表单数据，返回节点。底层基于 Formily `observer`——只追踪你读到的那片数据，**只有那片数据变化才重渲染**。

## 两种用法

- **不带 `name`** — 订阅整个 `form.values`，任一字段变化都重渲染
- **带 `name`** — 只订阅该字段的叶子值，**只有该叶子变化才重渲染**，其它字段怎么变都不影响这里

`name` 走 `Form.Field` 同一套相对路径规则（`.foo` / `..foo` 在 `Form.Field` 内解析到当前行），放在数组/表格行内也能用。

</Demo>

```tsx title="订阅整个表单值 vs 订阅单字段"
import { Form } from 'rsform';

<Form initialValues={{ name: 'rsform', age: 1, status: 'draft' }}>
    <Form.Field name="name" title="名称">
        <Form.Input />
    </Form.Field>
    <Form.Field name="age" title="数量">
        <Form.InputNumber min={0} />
    </Form.Field>
    <Form.Field name="status" title="状态">
        <Form.Select options={STATUS} />
    </Form.Field>

    {/* 订阅整个表单值——任一字段变化都更新 */}
    <Form.Consumer>{(values) => <pre>{JSON.stringify(values)}</pre>}</Form.Consumer>

    {/* 只订阅 name——只有 name 变化才更新，改 age/status 不重渲染 */}
    <Form.Consumer name="name">{(name) => <span>{name}</span>}</Form.Consumer>
</Form>
```

## 关键行为

- **不带 `name`** 读 `form.values`（深可观察），任一字段变化都触发重渲染
- **带 `name`** 读 `form.getValuesIn(name)`（叶子），只有该叶子变化触发重渲染——相邻字段编辑不波及
- **相对路径** — 在 `Form.Field name="rows.0"` 内用 `<Form.Consumer name="qty">`，解析为 `rows.0.qty`

:::warning
不要在 `children` 里做副作用（写状态、发请求）——它是纯渲染函数。需要副作用用 `effects` 里的 `$.onFieldValueChange`。
:::

## 何时用 Consumer vs effects

| 场景 | 用什么 |
| --- | --- |
| 把表单值**显示**出来（汇总、镜像、派生展示） | `Form.Consumer` |
| 字段变化时**改其它字段值 / 触发校验 / 发请求** | `effects`（`$.onFieldValueChange` / `$.linkedFieldProps`） |
| 表单外部按钮读取 / 提交当前值 | `formRef.current.values` / `formRef.current.submit()` |

一句话：**只读展示用 Consumer，写值联动用 effects**。

## 底层原理

直接 `const values = form.values` 拿到的是快照，字段变化时**不会**触发组件重渲染——必须包在 `observer` 里读才响应式。`Form.Consumer` 就是把这层 `observer` + 叶子订阅封装成声明式组件。

不用它，等价写法是手动 `useForm` + `observer` 包一层——同样响应式，只是样板多了：

```tsx title="等价的手写实现"
import { useForm } from '@formily/react';
import { observer } from '@formily/reactive-react';

// 等价于 <Form.Consumer>{values => …}</Form.Consumer>
const WholeValues = observer(function WholeValues({ children }) {
    const form = useForm();
    return <>{children(form.values)}</>;
});

// 等价于 <Form.Consumer name="name">{name => …}</Form.Consumer>
const FieldValue = observer(function FieldValue({ name, children }) {
    const form = useForm();
    return <>{children(form.getValuesIn(name))}</>;
});
```

关键点：**必须包在 `observer` 里读**，否则拿到的是快照、字段变化不重渲染。`Form.Consumer` 只是把这层样板封成了声明式组件——不是魔法，只是省事。
