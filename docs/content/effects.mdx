## Effects 响应式联动

`effects` 回调收到一个 `$` helper 集合。声明式地描述字段联动，无需手动
订阅/卸载——依赖字段任一变化即重跑，字段卸载自动拆卸。

### `$.validateField(key, triggers, cb)`

跨字段响应式校验。`triggers` 是依赖字段名数组，任一变化即重跑 `cb`；
`cb` 返回空串表示通过，非空串为错误信息。

### `$` helper 全集

| helper | 用途 |
|---|---|
| `onFieldReact(pattern, cb)` | **响应式联动（初始化 + 变化都执行）**。字段 init 时跑一次 cb，之后字段任一 observable 变化（value/visible/...）再跑。替代「`onFieldValueChange` + `ON_FIELD_MOUNT` 凑两段」的写法。Formily v2 原生 |
| `onFieldValueChange(pattern, cb)` | 字段值变化监听（**初始化不执行**，只在 value 变化时触发）。Formily v2 原生 |
| `linkedFieldProps(key, deps[], asyncCb)` | 异步派生字段 props（如级联 options） |
| `validateField(key, triggers[], cb)` | 跨字段响应式校验 |
| `onEachRowChange(pre, key, cb)` | 数组按行单 key 联动 |
| `onEachRowMultiChange(pre, keys[], cb)` | 数组按行多 key 联动 |

### `$.onFieldReact(pattern, cb)` —— 初始化 + 变化都执行的联动
> `onFieldReact` 的 `cb` 收到 `(field, form)`；`field.value` 是当前值。回调里用 `$.form.setFieldState` 改其它字段。`onFieldReact` 追踪字段所有 observable（不只是 value），所以 value/visible/display 变化都会重跑——适合「值驱动显隐 / 联动 props」场景。
>
> 只有「明确只想在值变化时触发、初始化不要」时才用 `$.onFieldValueChange`。
