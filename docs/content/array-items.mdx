## ArrayItems 可增删列表

轻量增删/移动列表，类似 antd `Form.List`。基于 Formily `ArrayField` mutators，行末
上移/下移/删除按钮走 Formily `moveUp`/`moveDown`/`remove`——不引入拖拽库，零额外依赖。
行内字段用 `name="email"`（无前导点 = append 到当前行 → `members.N.email`）自动绑到当前行。

### 属性

| 属性 | 默认 | 说明 |
|---|---|---|
| `name` | — | 数组字段名 |
| `itemDefaultValue` | `{}` | 新增行的默认值 |
| `min` / `max` | — | 行数上下限，到限禁用对应按钮 |
| `validateBeforeAdd` | — | 新增前门禁，返回 `false` 静默阻止，`string` 报错 |
| `addDisabled` | `false` | 隐藏新增按钮 |

### 跨行唯一校验

`arrayUnion(key)` 挂在行内 `<Field validator={arrayUnion('email')}>` 上，自动读取最近的
数组祖先，若该 `key` 在其他行已出现则报错。上例用于保证成员邮箱不重复。
